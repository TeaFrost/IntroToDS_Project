Trước mắt hiện tại trong file đang có 2 files là gitignore và main ipynb 
do dataset nặng tới 22 gb, không úp được lên trên gíthub ( và nếu ai có nhu cầu tải về file raw) thì làm như sau:
mở terminal/command promt của máy rồi nhét lệnh này vào:
```
pip install kagglehub pandas
```
tiếp theo vào acc kaggle --> kaggle setting --> tìm mục API --> Create new token.
lưu token vào máy theo hướng dẫn của kaggle (chạy lệnh tạo tệp cấu hình token trong Terminal).
tiếp theo là Clone repository này về máy
```
git clone [https://github.com/TeaFrost/IntroToDS_Project.git](https://github.com/TeaFrost/IntroToDS_Project.git)
```
mở file main.ipynb rồi chạy code trong file ấy là dữ liệu (RAW nhá, chưa lọc gì đâu) sẽ chạy về máy.
